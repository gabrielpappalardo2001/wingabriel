# WinGabriel

Programma per Windows pensato per chi usa un lettore di schermo. Sito: [wingabriel.it](https://www.wingabriel.it).

## Cartelle

- `WinGabriel` – il programma principale
- `wgcontrols` – le librerie del programma (una per funzione)
- `WGUpdater` – l'aggiornatore
- `WGLettore` – il lettore di schermo di WinGabriel
- `scripts/server` – i server di chat, giochi e del motore d'attesa, e gli script dei rilasci (`wgrilascia`, `wgpacchetti`)

## Rilasci

I rilasci ufficiali sono firmati. Si installano e si aggiornano da WinGabriel, che li prende dal sito e, se il sito non risponde,
dai [rilasci di questo repository](https://github.com/gabrielpappalardo2001/wingabriel/releases).
