Documentazione tecnica dei moduli esterni di WGLettore

Panoramica

Un modulo esterno è una libreria di classi compilata per .NET Framework 4.8, scritta in Visual Basic .NET oppure in C#, che estende il lettore di schermo aggiungendo la gestione specifica per un determinato programma senza dover ricompilare l'eseguibile principale. WGLettore include già moduli interni per Esplora risorse, Excel, Word, PowerPoint, i terminali e i browser web; i moduli esterni servono per gestire tutti gli altri programmi.

Creare un modulo

  1. Crea un nuovo progetto di tipo Libreria di classi (.NET Framework) impostando come versione del framework .NET Framework 4.8.
  2. Aggiungi al progetto il riferimento all'assembly WGLettoreSchermo.dll.
  3. Scrivi una classe pubblica, non astratta e dotata di costruttore senza parametri, che eredita da ModuloEsternoLettore nello spazio dei nomi WGLettoreSchermo.
  4. Compila il progetto e copia il file DLL generato all'interno della cartella moduli, situata nella medesima cartella di WGLettoreSchermo.dll.
  5. Riavvia il lettore di schermo per caricare la libreria. Il caricamento avviene esclusivamente all'avvio del lettore e solo dalla cartella moduli.

Riferimento della classe base

La classe base ModuloEsternoLettore mette a disposizione cinque membri ridefinibili. La proprietà Programmi è l'unico membro obbligatorio.

MembroTipo di ritornoQuando viene chiamatoValore predefinito
ProgrammiString()All'avvio, per identificare gli eseguibili associati al modulo. Proprietà di sola lettura (MustOverride).Nessuno (obbligatorio)
AlFuoco(frase As String, nomeElemento As String)StringQuando il fuoco di sistema passa su un elemento del programma gestito. frase indica il testo che il lettore pronuncerebbe, nomeElemento contiene il nome dell'elemento secondo UI Automation.Restituisce frase invariata. Se restituisce Nothing, viene usata la frase originale.
AlTasto(codiceTasto As Integer, ctrl As Boolean, maiuscolo As Boolean, alt As Boolean)StringPressione dei tasti di spostamento e di modifica nel programma. codiceTasto indica il codice di tasto virtuale di Windows (VK_*).Restituisce una stringa vuota "".
Formato()StringPressione della combinazione per la lettura del formato (tasto comandi + F).Restituisce una stringa vuota "" (in tal caso il lettore usa la lettura del formato tramite UI Automation).
BarraStato()StringPressione della combinazione per la lettura della barra di stato (tasto comandi + Fine).Restituisce una stringa vuota "".

Per la proprietà Programmi, occorre indicare i nomi degli eseguibili in minuscolo e senza estensione .exe (ad esempio notepad++). Il confronto tra stringhe non distingue maiuscole e minuscole. Qualora due moduli dichiarino lo stesso eseguibile, ha la precedenza l'ultimo modulo caricato.

Nel metodo AlTasto, se la funzione restituisce una stringa non vuota, il lettore la pronuncia in coda senza interrompere il parlato corrente. La pressione del tasto viene comunque inviata all'applicazione sottostante: il modulo non ha la possibilità di intercettare o bloccare il tasto.

Esempio

Imports WGLettoreSchermo

Public Class ModuloBloccoNoteInPiu
    Inherits ModuloEsternoLettore

    Public Overrides ReadOnly Property Programmi As String()
        Get
            Return New String() {"notepad++"}
        End Get
    End Property

    Public Overrides Function AlFuoco(frase As String, nomeElemento As String) As String
        Return "editor, " & frase
    End Function

    Public Overrides Function AlTasto(codiceTasto As Integer, ctrl As Boolean, maiuscolo As Boolean, alt As Boolean) As String
        Return ""
    End Function

    Public Overrides Function Formato() As String
        Return ""
    End Function

    Public Overrides Function BarraStato() As String
        Return ""
    End Function
End Class

Comportamento e limiti

  • Tutte le chiamate rivolte ai moduli sono protette da una gestione delle eccezioni. Se un metodo del modulo solleva un'eccezione, il lettore scrive l'errore nel registro degli errori e prosegue l'esecuzione standard. Il modulo non viene disattivato e l'eccezione verrà registrata nuovamente alla chiamata successiva.
  • I metodi vengono eseguiti durante l'elaborazione degli eventi del lettore e non nel thread dell'interfaccia grafica dell'applicazione target. La risposta deve avvenire entro poche decine di millisecondi per evitare che la voce ritardi rispetto agli spostamenti del fuoco. È vietato aprire finestre di dialogo, effettuare operazioni di rete bloccanti o accedere direttamente a controlli Windows Forms.
  • I moduli esterni non possono sovrascrivere la gestione dei programmi per i quali il lettore possiede già un modulo interno (Esplora risorse, Excel, Word, Outlook, PowerPoint, terminali, browser, Thunderbird, Teams, Calcolatrice e Blocco note). Per questi programmi i moduli esterni vengono ignorati.
  • Le librerie DLL vengono caricate nello stesso processo del lettore di schermo, il quale può essere eseguito con privilegi elevati. La cartella moduli deve essere protetta in scrittura allo stesso modo della cartella principale del programma e devono essere caricate esclusivamente librerie di provenienza fidata.
  • Una singola DLL può contenere più classi che ereditano da ModuloEsternoLettore: l'avvio del lettore le individuerà ed eseguirà tutte.
  • Se una DLL non può essere caricata a causa di un errore, viene registrata nel registro degli errori e saltata, senza impedire il caricamento delle altre librerie valide.

Provare e correggere un modulo

Durante la fase di sviluppo di un modulo, è possibile utilizzare le seguenti combinazioni di tasti messe a disposizione dal lettore di schermo. Il tasto comandi corrisponde al tasto Insert, a Bloc maiusc oppure a entrambi, a seconda dell'impostazione scelta.

  • Tasto comandi + F: richiama il metodo Formato() del modulo.
  • Tasto comandi + Fine: richiama il metodo BarraStato() del modulo.
  • Tasto comandi + H: ripete l'ultima frase pronunciata dal lettore. Aggiungendo il tasto Shift si risale alle frasi precedenti (una frase indietro ad ogni pressione). Aggiungendo il tasto Control si copia l'ultima frase pronunciata negli appunti di Windows.
  • Tasto comandi + F10: salva l'albero UI Automation dell'elemento che possiede il fuoco all'interno di un file di testo posizionato nella cartella dati lettore (accanto al file di configurazione). Permette di analizzare nomi, tipi di controllo e proprietà esposte dal programma target.
  • Tasto comandi + 1: attiva l'aiuto tasti, annunciando la funzione associata ad ogni pressione senza eseguirla.

Profili per programma

Ogni programma può disporre di un profilo personalizzato per regolare il livello di dettaglio della sintesi vocale (valori da 0 a 2) e l'eco della digitazione per caratteri e parole. È possibile salvare il profilo del programma attivo premendo Tasto comandi + Control + 0 ed eliminarlo premendo Tasto comandi + Shift + 0, oppure agendo tramite la scheda Profili nella finestra delle impostazioni del lettore.

Nel file di configurazione condivisa, il profilo viene registrato nella chiave lettore_schermo_profilo_ seguita dal nome dell'eseguibile in minuscolo e privo di estensione. Il valore viene memorizzato nella forma p=1;c=1;w=1 (dove p indica la prolissità, c l'eco dei caratteri e w l'eco delle parole, con valore 1 per attivo e 0 per disattivato). I parametri vengono applicati in memoria all'ingresso del programma e ripristinati ai valori generali all'uscita, senza modificare la configurazione globale.

Il modulo per i terminali

WGLettore include un modulo interno dedicato alle applicazioni di terminale e console, quali Windows Terminal, conhost, cmd, PowerShell, pwsh, WSL, PuTTY e mintty. Il modulo legge ogni nuova riga inviata in uscita, una per volta. La pressione del singolo tasto Shift interrompe la lettura della riga corrente e passa a quella successiva, mentre i tasti Invio e Control + C azzerano immediatamente la voce.

Per esaminare il contenuto dello schermo senza spostare il cursore di sistema, sono disponibili le seguenti scorciatoie da tastiera:

  • Tasto comandi + Control + Freccia sinistra / Freccia destra: legge la riga precedente o successiva.
  • Tasto comandi + Control + Freccia su: legge la prima riga dello schermo.
  • Tasto comandi + Control + Freccia giù: legge l'ultima riga dello schermo.
  • Tasto comandi + B: legge l'intero schermo visibile.

Utilizzando la disposizione della tastiera da tavolo, le stesse funzioni di consultazione possono essere eseguite tramite i tasti 4, 6, 8 e 2 del tastierino numerico. La rilettura prende come riferimento iniziale la posizione attuale del cursore.
